# UsageBar releases

Built installers for UsageBar, Stocksdigital's AI usage monitor for the Windows taskbar. This repo only contains release files; the source code is private.

- **Download:** [latest Windows installer](https://github.com/StocksDigital/usagebar-releases/releases/latest)
- **Updates:** installed copies of UsageBar check this repo's `latest.json` and update themselves.

The usage engine is built from [Win-CodexBar](https://github.com/nesszer/Win-CodexBar) (MIT). Provider logos are trademarks of their owners.
